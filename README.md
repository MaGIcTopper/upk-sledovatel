# ⚖️ Кабинет следователя — рабочий справочник

Статический сайт-справочник для следователей и дознавателей: алгоритмы процессуальных действий, сроки по УПК РФ, ключевые статьи и материалы, разбитые по ведомствам.

🌐 **Сайт:** https://magictopper.github.io/upk-sledovatel/

## Что внутри

**Общее**
- 📋 **Алгоритмы действий** — пошаговые чек-листы по ключевым процессуальным ситуациям (отметки сохраняются в браузере)
- ⏱ **Сроки и калькулятор** — таблица сроков по УПК РФ и расчёт контрольных дат
- 📖 **Ключевые статьи** — нормы УПК РФ, которые применяются ежедневно
- 💡 **Памятки** — типичные ошибки, правила составления протокола, права участников
- 📁 **Общие материалы** — образцы протоколов, справочные документы

**По ведомствам**
- 🚔 Следователи МВД
- 🏛 Следователи СК
- 🛡 Следователи ФСБ
- 📝 Дознаватели

В каждой категории — краткая справка о подследственности и свои материалы.

## Структура репозитория

```
├── index.html        — весь сайт (страницы, стили и скрипты в одном файле)
├── README.md         — этот файл
└── files/            — PDF и Word-файлы, доступные на сайте
```

## Как добавить материал

1. Загрузите файл в папку `files/` (имя лучше писать латиницей, без пробелов).
2. Откройте `index.html` и найдите массив `MATERIALS`.
3. Добавьте строку:

```js
{cat:'mvd', group:'Макеты уголовных дел', title:'Название материала', file:'files/имя_файла.pdf'},
```

Значения `cat`: `general` (общее), `mvd`, `sk`, `fsb`, `dozn`.
Необязательное поле `desc:'краткое описание'` покажет подпись под названием.

4. Сохраните изменения (Commit changes) — через 1–3 минуты сайт обновится.

## Публикация

Сайт размещён на GitHub Pages: **Settings → Pages → Deploy from a branch → `main` / `(root)`**.

## ⚠️ Важно

Материал носит информационно-справочный характер и не заменяет текст закона. Перед принятием процессуального решения сверяйтесь с действующей редакцией УПК РФ, УК РФ и иных нормативных актов.
